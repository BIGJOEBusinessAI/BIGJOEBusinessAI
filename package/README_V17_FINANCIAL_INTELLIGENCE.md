# BIGJOE v17 — Financial Intelligence Centre

Adds a professional financial centre combining Sales, COGS, Expenses, Customer Receivables, Supplier Payables and Inventory into one view.

## Features
- Profit & Loss for a selected date range
- Gross profit and net profit/loss
- Cash inflow/outflow and net cash movement
- Customer receivables and supplier payables snapshot
- Inventory value and working capital
- Expense concentration
- Largest customer and supplier balances
- Monthly financial trend
- Print / Save as PDF
- CSV export

The module is read-only and preserves all existing v16 records and features.
