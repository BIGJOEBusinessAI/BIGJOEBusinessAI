BIGJOE v5 Dashboard & Reports

This version preserves the working Inventory, Products, Categories, Suppliers, Sales/POS, Customers, customer purchase history and Flutterwave test integration.

New Dashboard features:
- Date-filtered sales/revenue/profit dashboard
- Units sold and average sale
- Inventory value
- Daily sales chart
- Best-selling products
- Top customers
- Payment-method breakdown
- Low-stock alerts
- Management summary and print report

Run:
1. Extract the ZIP.
2. Open Command Prompt in the project folder.
3. Run: node server.js
4. Open: http://127.0.0.1:8000
