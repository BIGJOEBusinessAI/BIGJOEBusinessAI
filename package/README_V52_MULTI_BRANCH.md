# BIGJOE v52.0 — Multi-Branch Intelligence & Consolidated Reporting

Adds consolidated multi-branch reporting to the existing Branches module.

## New
- Consolidated revenue, gross profit, expenses, net profit and inventory value.
- Branch-by-branch comparison for a selected date range.
- Gross-margin comparison across branches.
- Date filtering for consolidated reports.
- Existing branch selection and stock transfer workflows preserved.

## Data safety
Keep the existing `data/db.json`; v52 uses the current business database and does not require a destructive migration.
