# BIGJOE v34 — Budget & Cost Control Centre

Adds category-level expense budgets, current-month budget-vs-actual analysis, three-month expense trend, cost-control alerts and management recommendations.

Existing v33 Cash Flow, Scenario Centre, Business Planner, Dashboard, accounting, POS, inventory, loyalty and customer features are preserved.

## Testing
1. Start BIGJOE with `start.bat`.
2. Log in and open **🧾 Budget Control**.
3. Add category budgets and optionally set an overall monthly expense limit.
4. Save and verify the budget-vs-actual table and alerts.
5. Add an expense and refresh; the actual and remaining budget should update.
