# BIGJOE v12.4 — Inventory Valuation Fix

This release refines the Inventory Valuation report card so its five columns remain readable inside the two-column Reports layout.

### Fixed
- Product names no longer break into individual characters.
- Stock quantities remain readable.
- Currency columns retain their values on one line.
- Column widths are balanced for the report card.
- The card no longer needs a horizontal scrollbar for the Inventory Valuation report.
- Existing business logic and data are unchanged.
