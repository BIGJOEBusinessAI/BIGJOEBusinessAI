# BIGJOE

BIGJOE is a business management desktop app that helps businesses make smarter decisions by turning their everyday data into clear insight. It brings together sales, inventory, customers, and supplier records in one place, so business owners can spot trends and make informed decisions instead of guessing.

## Features

- 📊 **Sales tracking** — record and review sales activity over time
- 📦 **Inventory management** — keep tabs on product stock levels
- 👥 **Customer records** — manage customer information and history
- 🤝 **Supplier management** — track suppliers and related data
- 📈 **Data-driven insights** — use recorded data to guide business decisions

## Installation

Head to the [**Releases page**](https://github.com/BIGJOEBusinessAI/BIGJOEBusinessAI/releases/latest) and download the file for your system:

| System | File to download |
|---|---|
| Windows | `BIGJOE-Business-AI-Setup-X.X.X.exe` |
| Mac | `BIGJOE-Business-AI-X.X.X-arm64.dmg` |
| Linux | `BIGJOE-Business-AI-X.X.X.AppImage` |

**Windows:** Double-click the `.exe` file and follow the setup wizard. If Windows shows a "protected your PC" warning (this happens because the app isn't signed with a paid certificate yet), click **"More info"** → **"Run anyway"**.

**Mac:** Open the `.dmg` file and drag BIGJOE into your Applications folder. If macOS blocks it as from an "unidentified developer," go to **System Settings → Privacy & Security**, scroll down, and click **"Open Anyway"**.

**Linux:** Download the `.AppImage` file, right-click it → **Properties** → **Permissions** → check **"Allow executing file as program"**, then double-click to run it. (Or from a terminal: `chmod +x BIGJOE-Business-AI-*.AppImage` then run it.)

BIGJOE will check for updates automatically and prompt you when a new version is available.
