# BIGJOE v57.6 — Overview Boundary & Plans/Flutterwave

## Changes
- Authenticated Overview is now a hard-separated application screen. Public Welcome/marketing sections are hidden before Login and never remain above Overview after login.
- Overview begins with the small BIGJOE logo, account-owner greeting, and Log out control, followed by the static blue navigation bar.
- Plans page now presents exactly three subscription plans: Free Forever, Business, and Pro.
- Paid Business/Pro plans use the existing BIGJOE Flutterwave checkout endpoint. The checkout URL is generated by Flutterwave at payment time; no secret key is stored in the frontend.
- Free Forever has no payment action.
- Responsive plan cards reflow for laptop/tablet/phone screens.

## Flutterwave setup
The project continues to use `FLW_SECRET_KEY` in `.env` for the server-side Flutterwave integration. The provided `.env.example` contains a placeholder only. Keep your real Flutterwave test/live secret key private.

## Test flow
1. Open BIGJOE and confirm only the Welcome page is visible.
2. Click Start Free and confirm only the Login page is visible.
3. Log in and confirm the Overview starts at the small BIGJOE logo + Welcome greeting, with no Welcome/advertising content above it.
4. Open Features → Plans and verify Free Forever, Business, and Pro.
5. Click Business or Pro and confirm Flutterwave checkout opens.
