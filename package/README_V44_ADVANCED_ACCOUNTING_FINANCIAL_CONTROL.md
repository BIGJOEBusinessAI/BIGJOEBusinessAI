# BIGJOE v44.0 — Advanced Accounting & Financial Control

Built on v43.1. Adds a Financial Control Check to the Accounting page.

## Highlights
- Trial balance integrity check (debits vs credits)
- Balance sheet integrity check
- Net profit/loss visibility
- Closing cash visibility
- Period-aware control checks using the existing accounting APIs
- Preserves existing chart of accounts, cashbook, financial statements, trial balance and general ledger

Keep the existing `data/db.json` when upgrading.
