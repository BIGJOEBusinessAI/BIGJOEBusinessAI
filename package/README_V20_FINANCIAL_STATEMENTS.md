# BIGJOE v20 — Financial Statements

Adds automatic Profit & Loss, Balance Sheet and Cash Flow statements to Accounting.

- Uses existing sales, expenses, receivable payments, supplier payments and manual cashbook entries.
- Includes period filtering.
- Adds print and CSV export.
- Balance sheet shows a balance check and clearly labels accumulated/unallocated equity.
- Existing data/db.json is preserved.
