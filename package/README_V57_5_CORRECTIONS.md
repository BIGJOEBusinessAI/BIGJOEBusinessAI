# BIGJOE v57.5 — Navigation, Data Loading & Responsive Corrections

Implemented:
- Refresh control on every page where a dedicated refresh action was not already present.
- Preload dashboard/business data during owner login so primary figures are available immediately.
- Added Overview to the authenticated leaderboard.
- Receipt/business branding now uses merged business-profile defaults and prefers the registered business name when present.
- Added Show/Hide password control to login.
- Reworked Data Protection & Audit Centre filters and table layout for clearer review on desktop and mobile.
- Fixed Plans page loading and presentation.
- Reworked leaderboard buttons to auto-wrap/reflow at reduced screen widths.
- Added missing page loaders for Payment Hub and Business Command Center.

The package is based on the tested BIGJOE v57.4 project. Preserve the working `data/db.json` when upgrading an existing installation.
