# BIGJOE v12 — Management Reports & Decision Center

This version builds on BIGJOE v11 Advanced Business Advisor.

## New features
- Management Reports navigation page
- Profit & Loss report
- Sales Performance report
- Expense report with category shares
- Inventory Valuation report
- Customer Performance report
- Executive management summary
- Management priorities generated from live dashboard intelligence
- Date-range filters
- Print-ready management report
- CSV export

## Existing features preserved
Sales/POS, inventory, products, categories, suppliers, customers, expenses, dashboard, advanced analytics, AI Business Advisor and Flutterwave test-mode integration.

## Run
Use `start.bat` or run `node server.js`, then open http://127.0.0.1:8000.
